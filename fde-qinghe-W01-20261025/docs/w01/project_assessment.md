# 青禾优选 W01 项目初步评估

## 一、客户实际要解决什么业务问题？

沈总希望改善会员复购下滑的问题，并在三个月内看到复购率止跌回升。他将这一业务结果作为考虑是否继续投入的重要依据。

沈总在邮件及访谈中表示，青禾目前按约80万活跃会员看待该问题，复购率已连续四个季度下滑。但本周尚未取得对应报表、下降幅度、活跃会员定义及复购率计算方法，因此上述经营情况记录为角色转述，尚未核验。

“会员老化”是沈总提出的原因假设。他也承认需要数据支持，目前不能据此确定下滑原因或直接制定解决方案。

当前明确的优先任务是帮助小林识别需要重点经营的会员，并提供运营建议。尚未明确的是：“重点经营会员”怎样定义，小林目前怎样筛选，名单与建议由谁审核，以及后续由谁决定并执行运营动作。

三个月止跌回升目前是客户期望。目标增幅、统计口径、评估范围、判定依据及验收责任均未确定，尚未形成双方确认的效果承诺。

依据：沈总立项邮件MAIL-W01-001、公司与项目协作关系BRIEF-W01-001，以及首轮正式访谈。访谈具体定位见fit-gap证据明细。

## 二、标准产品为什么可能适用，能力边界在哪里？

标准产品具备会员、订单和门店样例数据分析能力，可按明确时段比较老会员净消费，识别达到下降阈值的人群，并输出供人工审核的建议与依据。这与“识别需要关注的会员、提供运营建议”的方向有联系，因此值得进一步核实客户适配条件。

结合目前五条fit-gap，初步判断如下：

- GAP-001：产品已有标准净消费、老会员和下降定义，但青禾的重点经营会员规则未明确，适配方式待判断。
- GAP-002：公开材料已明确产品尚未接入青禾数据及系统，初步归为系统适配；具体接口、字段、权限和工作量仍需核实。
- GAP-003：标准产品在样例上已有建议和依据输出能力。建议是否贴合青禾业务、是否便于小林使用，仍需客户参与验证。
- GAP-004：三个月复购改善属于业务目标，当前不作效果承诺。
- GAP-005：约80万活跃会员的规模来自沈总转述，本周小规模样例测试不能证明实际规模下的可用性和性能，需另行核实并测试。

能力边界主要依据CAP-003、CAP-004、CAP-006等产品能力说明。样例标签能力属于CAP-007，不能据此认定已具备青禾标签或发券系统的连接能力。CAP-008也说明当前是本地教学产品，生产认证、多用户隔离等能力需要后续扩展与验证。

依据：product/capabilities.json、产品README与API说明，以及artifacts/w01/中的模型基线、运行证据和Promptfoo报告。

## 三、进入下一阶段需要哪些数据、协作与决策条件？

下一阶段需要取得以下证据：

| 对象 | 需要核实或取得的内容 | 对判断的影响 |
| --- | --- | --- |
| 小林 | 复购及活跃会员定义、重点经营会员规则、现有报表、典型任务、筛选及审核执行流程 | 明确助手进入哪个工作环节，以及怎样判断输出有用 |
| 老周 | 数据来源、字段说明、脱敏样本、关联关系、时间覆盖、更新频率、访问权限和接入条件 | 判断数据能否支持分析，明确适配范围和规模测试要求 |
| 陈姐 | 门店执行方式、人员条件及业务限制 | 判断名单和建议能否落地 |
| 王经理及业务相关方 | 预算、合同、验证范围、审批流程、验收责任和继续投入条件 | 判断下一阶段是否具备启动条件 |

本周只取得沈总访谈。上述其他角色的信息是后续核查计划，不代表已取得其意见或资源承诺。王经理需要参与预算和合同，也不代表已确认其为最终批准人。

沈总提出，开始前至少需要明确复购率口径、目标增幅及验收标准，但目前均未确定。因此，在确定实施范围和承诺前，还需要对齐目标、评估依据、审批与责任分工。

主要风险是：以未经验证的原因假设指导方案；指标或验收标准不一致；数据质量、覆盖或权限不足；名单后的审核执行责任不明确；将样例成功误认为客户适配和业务效果已验证。

## 四、现在应继续、带条件继续，还是暂缓？

建议带条件继续。下一阶段先开展需求核实、数据条件确认和验证方案设计，暂不直接承诺客户实施范围或三个月复购改善效果。

本阶段的投入范围限于：澄清目标与工作流程、核查数据条件、对照标准能力，并形成可评审的验证方案。具体工期、人力和预算需要另行确认。

进入客户数据验证前，应至少明确：

1. 目标人群、复购率及相关指标的定义。
2. 数据取得方式、使用权限及必要质量条件。
3. 验证范围、协作责任人及审批安排。
4. 验证结果如何评审，以及与三个月业务目标是什么关系。

可提出先验证：会员筛选规则能否复算，结果能否追溯，建议能否由运营人员审核和使用，以及缺数据和权限受限时能否正确处理。这些是拟议验证重点，具体验证标准仍需与客户共同确认。

如果关键定义无法对齐、数据无法取得或不满足分析条件，或者缺少必要的业务责任人，应缩小验证范围或暂缓相应工作。取得新证据后，更新fit-gap和推进判断。

当前能够说明的是标准产品在本周样例中的已验证能力，以及下一阶段需要补齐的条件。尚不能承诺三个月复购一定回升，也不能宣称已完成青禾数据接入、规模验证或生产系统写入能力建设。
